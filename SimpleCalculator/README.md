# Simple Calculator Using React.js

## About the Project

The Simple Calculator is a web application developed using React.js. It performs basic arithmetic operations with a simple and user-friendly interface.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Delete (DEL) functionality
- Reset functionality
- Clear calculator display
- Dark-themed user interface

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/simple-calculator-react.git
   ```

2. Navigate to the project folder:

   ```bash
   cd simple-calculator-react
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal.

## How to Use

1. Click the number buttons to enter values.
2. Select an arithmetic operator.
3. Enter the next number.
4. Press `=` to calculate the result.
5. Use `DEL` to delete the last character.
6. Use `RESET` to clear the display.

## Purpose

This project demonstrates the use of React components, the `useState` hook, event handling, and CSS styling to develop a simple calculator application.
