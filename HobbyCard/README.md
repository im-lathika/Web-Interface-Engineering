# Hobby Card

A responsive Hobby Card web application built using React JS and CSS.

## Features

- Displays six hobbies: Reading, Painting, Music, Photography, Gardening, and Cooking.
- Reusable React components.
- Images and descriptions for each hobby.
- Responsive two-column layout for desktop and single-column layout for mobile.
- Simple and clean user interface.

## Technologies Used

- React JS
- JavaScript
- CSS3
- Vite

## Getting Started

### Installation

```bash
npm install
```

### Run the Application

```bash
npm run dev
```

Open the local URL displayed in the terminal.

### Build for Production

```bash
npm run build
```
