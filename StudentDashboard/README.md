# Student Dashboard

A responsive student dashboard built using React, JavaScript, and CSS.

## Features

- Student profile and academic details
- Reusable React components
- Semester subject list
- Total subject count
- Attendance eligibility status
- Placement status
- Responsive layout

## Technologies Used

- React JS
- JavaScript
- CSS3
- Vite

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
